LSTM-Driven Portfolio Optimization on NEPSE using Differential Evolution

Nov 2025 – May 2026

Undergraduate thesis

  • Formulated a mixed-integer nonlinear portfolio optimization problem under real-world market constraints and solved it with Differential Evolution, using a custom decode-and-repair operator to keep integer-lot solutions feasible.
  • Combined sector-level LSTM networks with attention for return signals, Ledoit–Wolf shrinkage for covariance estimation, and a penalty-augmented Sharpe ratio objective; ran a systematic sensitivity analysis over the key hyperparameters.

Image Compression Using Singular Value Decomposition

May 2025 – Jul 2025

Mathematics seminar project

  • Applied truncated SVD to lossy grayscale image compression, grounded in the Eckart–Young–Mirsky theorem on optimal low-rank approximation in the Frobenius norm.
  • Built the pipeline in Python (NumPy, OpenCV) with rank selection by energy preservation, reaching compression ratios up to 17:1 on 512×512 images, evaluated with PSNR and SSIM.

Physics-Informed Neural Networks vs. Finite Differences for the Heat Equation

Dec 2024 – Apr 2025

Independent project · Code on GitHub

  • Benchmarked PINNs against explicit, implicit and Crank–Nicolson finite-difference schemes for the 1D, 2D and 3D heat equations, comparing accuracy, runtime and memory under coarse discretization.
  • Trained PINNs with adaptive GradNorm loss weighting, Latin Hypercube Sampling and Adam/L-BFGS. Finite differences were more accurate; PINNs were faster in 3D.
